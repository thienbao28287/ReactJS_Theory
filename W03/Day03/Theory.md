## Kiến thức trọng tâm

### 1. Setup phải có đối ứng

setInterval đi với clearInterval; addEventListener đi với removeEventListener bằng cùng callback. Cleanup chạy trước setup mới khi dependency đổi và khi unmount.

### 2. Tránh interval đọc state cũ

Nếu chỉ cần tăng từ giá trị trước, dùng setter dạng updater trong interval. Không cần thêm seconds vào dependency rồi tạo lại interval mỗi giây.

### 3. Kiểm tra bằng unmount

Nút ẩn/hiện component ở cha giúp phát hiện timer/listener còn sống. Không chỉ kiểm tra lúc component đang hiển thị vì rò tài nguyên thường lộ sau nhiều lần mount.

## Ví dụ có thể thử

Ví dụ React: đặt trong src/LessonDemo.jsx, dùng default import để hiển thị từ App.jsx. Đây là demo độc lập; không thay toàn bộ ứng dụng bán hàng bằng demo khi ghép tính năng.

```jsx
import { useEffect, useState } from 'react';
function Timer() {
  const [seconds, setSeconds] = useState(0);
  useEffect(() => {
    const id = setInterval(() => setSeconds(s => s + 1), 1000);
    return () => clearInterval(id);
  }, []);
  return <p>Đã học {seconds} giây</p>;
}
export default function LessonDemo() {
  const [visible, setVisible] = useState(true);
  return <section><button onClick={() => setVisible(v => !v)}>Ẩn/hiện</button>{visible && <Timer />}</section>;
}
```

Trước khi chạy, dự đoán kết quả; sau khi chạy, thay một đầu vào và giải thích điều gì đổi. Ví dụ làm rõ cơ chế của bài; phần bài tập yêu cầu bạn vận dụng thành tính năng riêng.

## Lỗi dễ mắc và cách kiểm tra

Dùng hai arrow function khác nhau cho add/remove listener; quên clearInterval khi unmount.

Khi lỗi xuất hiện, đọc terminal và Console trước; xác định lỗi ở dữ liệu, luồng cập nhật hay cách hiển thị. Chỉ sửa một nguyên nhân mỗi lần, chạy lại đúng thao tác gây lỗi rồi kiểm tra một trường hợp bình thường để tránh làm hỏng phần đang hoạt động.
